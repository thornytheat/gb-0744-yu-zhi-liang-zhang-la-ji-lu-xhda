# 数据字典

| 数据 | 字段 | 规则 |
|---|---|---|
| `targets` | `beam`, `strand`, `day`, `design_kn`, `L_mm`, `R_mm`, `L_anchor`, `R_anchor` | 梁号和钢束号保留前导零；日期是班组营业日；设计力用千牛，理论伸长和锚回缩用毫米。 |
| `readings` | `id`, `beam`, `strand`, `day`, `end`, `jack`, `level`, `force`, `unit`, `stroke`, `displacement_unit` | 左/右对应 L/R，力级支持 20%、40% 和 100%，`kN` 直读、`MPa` 按证书折算。位移默认毫米，可用 cm，旧表用 `extension`。 |
| `calibrations` | `jack`, `revision`, `from`, `until`, `slope`, `offset` | 有效日 `[from,until)`，换算千牛等于压力乘斜率加截距。存在多条同日有效的证书时，该压力读数隔离。 |

数值以 Decimal 计算，结果留三位小数供查阅，判定使用舍入前数值。相同流水编号且归一后完全一致的读数算重复，字段矛盾则隔离同号整组。在同一端和力级上存在两条合格读数时，保留竞争原因并要求复测。

对齐目标力 = 设计力 × 力级。目标前后 5% 均计为合格，端点包含在内。按两个低力级的实测载荷与位移建立直线并外推到零载，峰值位移减外推零点及回缩即有效伸长。每端绝对相对偏差上限为 10%，双端总和上限为 6%。这三个上限是演示工艺合同参数，实际工序应采用项目批准的工艺标准。缺力级或位移不严格增加的端位进入待复测。工程设计值和原始记录结构损坏时拒绝整个计算。

原读数 = 对齐 + 隔离 + 重复。梁号勾稽按设计钢束逐条分类。批号由内容与规则版本共同决定；重复上传只引用既有结果。文件上限 256 KiB，每个数据组最多 1200 行。

锚固回缩吃掉全部伸长（`NO_EXTENSION`）是真实结构问题，判验记「超限」并在处置单列为「锚回缩处置」，不按「待复测」带过；缺力级、位移倒序等记录不足才记「待复测」。

## 处置字段

| 数据 | 字段 | 规则 |
|---|---|---|
| `处置顺序` | `梁号`、`钢束`、`端位`、`端判验`、`处置类型`、`处置分组`、`处置依据`、`依据说明`、`下一步`、`今晚顺序`、`现场复张`、`停工`、`原读数` | 每个设计钢束的左右端各一行。`处置类型` 取该端最重原因：锚回缩处置、现场复张、合计复核、补测补录、记录核对、证书核对、放行。`下一步` 按该端每个原因给出动作（去重），明确标注是否安排现场复张。`今晚顺序` 仅在待处置端位间从 1 连续编号，现场处置排在记录处理之前。`原读数` 含该端所有原始行及采信状态。 |
| `梁发运` | `梁号`、`设计钢束`、`已通过钢束`、`待处置端位`、`阻断钢束`、`处置完毕`、`结论`、`可移交发运` | 每梁一行。全部设计钢束处置完毕且判验通过才 `可移交发运`。 |
| `移交结论` | — | 本批全部梁均可移交时为「可移交发运」，否则「暂缓发运」。 |
| `附带记录问题` | `源行`、`梁号`、`钢束`、`端位`、`原因码`、`处置类型`、`说明`、`下一步`、`原读数` | 无对应设计钢束等不能归到某一端的隔离行，同样保留原读数。 |

`处置类型` 到原因码的映射：`NO_EXTENSION` → 锚回缩处置（判验记超限，不按待复测）；`SIDE_TOLERANCE` → 现场复张；`TOTAL_TOLERANCE` → 合计复核；`MISSING_LEVEL`、`REVERSED`、`BAD_READING`、`FORCE_TOLERANCE` → 补测补录；`ID_CONFLICT`、`LEVEL_CONFLICT`、`NO_TARGET` → 记录核对；`CAL_OVERLAP`、`CAL_MISSING`、`CAL_NEGATIVE` → 证书核对；`DUPLICATE` 仅作采信说明，不另开处置。
